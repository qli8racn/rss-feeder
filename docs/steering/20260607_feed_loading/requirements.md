# フェーズ 1：RSS リンクの読み込み

## 概要

テキストファイルから RSS フィードの URL 一覧を取得する

> **注意**: フェーズ 8 でフィード管理が SQLite に移行済み。
> `feeds.txt` および file ドライバは削除された。
> 現在のフィード読み込みは `docs/steering/20260608_feed_management` を参照。

## 受け入れ条件（初期実装時）

- `feeds.txt` に改行区切りで記載された URL を読み込める
- 空行・コメント行（`#` 始まり）はスキップする
- URL が 0 件の場合は警告メッセージを出力して終了する
