# フェーズ：キュレーション機能（今日読む記事の提示）

## 概要

`bin/rss-agent curate` コマンドを追加する。
直近の記事とブックマーク履歴を元に、AIエージェントが「今日読む価値がある記事」を選定・推薦する。

## 背景・目的

このプロジェクトを日常利用ツールとして育てるにあたり、「大量の記事から自分に関係あるものだけ読みたい」という
ニーズに応える機能が必要。`rss-agent preference` はブックマークの傾向分析を行うが、出力はテキスト分析であり
記事そのものの選定は行わない。`curate` はその一歩先として、分析→選定→提示までをエージェントが担う。

## 目的

- 毎朝 `bin/rss-agent curate` を実行すると、その日に読む価値がある記事リストが得られる
- 記事の選定根拠（推薦理由）がわかるので、読むか否かの判断が速い

## 受け入れ条件

- `bin/rss-agent curate` コマンドが追加される
- エージェントがツール経由で以下を取得して推薦判断を行う
  - 直近記事（`fetch_recent_articles`）：title・URL・category・summary を含む
  - ブックマーク記事（`fetch_bookmarked_articles`）：趣向把握用
- 推薦記事をランク付きで出力し、各記事に推薦理由を付与する
- `--limit <n>` で考慮記事数を指定できる（デフォルト 30）
- enrich 済み記事を前提とする（summary/category が空の場合は title のみで判断）

## スコープ外

- 日付範囲によるフィルタリング（`--days` オプション）
- curate 結果の DB 保存
- 朝のスケジュール自動実行（cron 等）
- `rss-feeder` CLI への統合（`rss-agent` 専用コマンドとして実装）
