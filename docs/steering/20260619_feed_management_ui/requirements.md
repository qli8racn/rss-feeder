# フェーズ：フィード管理 Web UI

## 概要

RSS フィードの追加・一覧・削除は現在 CLI（`rss-feeder add-feed` / `list-feeds` / `remove-feed`）でのみ提供されている。
`docs/web-ui-spec.md` でも「フィード管理 UI」は明示的にスコープ外とされており、Web 画面からはフィードを増減できない。

本フェーズでは、既存の `AddFeedUsecase` / `ListFeedsUsecase` / `RemoveFeedUsecase` を Web API として公開し、
ブラウザ上でフィードの一覧表示・追加・削除を行える UI を追加する。

## 受け入れ条件

### Web API

- `GET /api/feeds` で登録済みフィードを ID・URL・タイトル・最終取得日時つきで一覧取得できる
- `POST /api/feeds` に `{ "feed_url": "<url>" }` を送信してフィードを追加できる
  - 追加に成功した場合、作成されたフィード情報を返す
  - `feed_url` が空の場合は 400 を返す
  - 既に登録済みの URL の場合は 409 を返す
- `DELETE /api/feeds/{id}` で指定 ID のフィードを削除できる（関連記事も連動削除される既存仕様を維持）
  - `id` が整数でない場合は 400 を返す
  - 存在しない `id` の場合は 404 を返す
- 上記 3 エンドポイントの仕様を `docs/openapi.yaml` に追加し、Go・フロントエンドの型をコード生成する

### フロントエンド

- ヘッダーに「フィード管理」を開くボタンを追加する（既存の「最新フィードを取得」「ブックマーク」ボタンと並列）
- フィード管理はモーダルで表示する（既存方針「ルーティングなし・単一画面」を維持するため新規ページは追加しない）
- モーダル内でできること
  - 登録済みフィードの一覧表示（URL・タイトル・最終取得日時）
  - URL 入力 + 追加ボタンによるフィード追加
  - 各行の削除ボタンによるフィード削除（削除前に確認ダイアログを出す）
- 登録済みフィードが 0 件の場合はガイドメッセージを表示する
- 追加・削除に失敗した場合（重複登録・存在しない ID 等）はモーダル内にエラーメッセージを表示する
- フィードの追加・削除は記事一覧画面の表示中の記事には影響しない（記事への反映は既存の「最新フィードを取得」ボタンの実行に委ねる。本フェーズでは自動取得・自動反映は行わない）

## スコープ外

- フィードの編集（URL 変更・タイトル手動編集）
- フィード追加時の URL 形式検証・実在チェック（取得は既存の `fetch` 実行時に失敗すれば判明する想定。本フェーズでは空文字チェックのみ行う）
- フィード追加と同時に記事を取得する自動 fetch（必要なら別フェーズで検討）
