# 設計：取得済み記事の一覧表示

## 対象コマンド

```bash
rss-feeder list [flags]
```

## フラグ

| フラグ | 説明 |
|------|------|
| （なし） | 未読記事のみ（デフォルト） |
| `--all` | 全件表示 |
| `--bookmarked` | お気に入りのみ表示 |

## 出力イメージ

```
ID   タイトル                          公開日時              既読  お気に入り
---  --------------------------------  --------------------  ----  ----------
 42  Go 1.23 リリースノート            2024-08-13 12:00      -     -
 43  net/http の新機能                 2024-08-13 12:01      ✓     ★
```

## 実装方針

- 表示後に `read = 1` へ自動更新（全フラグ共通）

## 関連ファイル

| ファイル | 役割 |
|---------|------|
| `internal/usecase/list.go` | 一覧取得・既読更新ロジック |
| `internal/adapter/handler/list.go` | cobra コマンド・テーブル出力 |
| `internal/driver/readerdb/article/article.go` | SELECT / UPDATE SQL |
