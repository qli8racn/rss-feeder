# smart-commit

ステージングの差分をレビューし、コミットメッセージを自動生成してユーザー確認後にコミットする。

## 手順

1. ステージングが空でないか確認する
   ```bash
   git diff --staged --stat
   ```
   空の場合は「ステージングに差分がありません」と伝えて終了する。

2. 差分の全内容を取得する
   ```bash
   git diff --staged
   ```

3. 差分を分析して以下を作成する
   - **コミットメッセージ**（1行、日本語、prefix付き例: `feat:` `fix:` `docs:` `refactor:`）
   - **変更の概要**（箇条書き3行以内）

4. ユーザーに提示して確認を求める
   ```
   📝 コミットメッセージ案:
   feat: ○○を追加

   変更概要:
   - ○○
   - ○○

   このメッセージでコミットしますか？ [y/修正内容/n]
   ```

5. ユーザーの返答に応じて処理する
   - `y` → `git commit -m "..."` を実行してコミットハッシュを表示
   - 修正内容を入力 → メッセージを修正して再度確認（手順4へ）
   - `n` → 「コミットをキャンセルしました」と伝えて終了

## 注意

- `git commit` はユーザー確認後にのみ実行する
- `--no-verify` は使用しない
- コミットメッセージは英語でも日本語でも、リポジトリの既存スタイルに合わせる
